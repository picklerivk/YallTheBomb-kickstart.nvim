# Configuration Files

This directory contains Linux configuration files organized by application.

## Directory Structure

```
config/
├── alacritty/          # Alacritty terminal emulator configuration
├── bash/               # Bash shell configuration
├── git/                # Git configuration
├── gtk-3.0/           # GTK 3.0 theming and configuration
├── i3/                # i3 window manager configuration
├── kitty/             # Kitty terminal emulator configuration
├── nvim/              # Neovim configuration (moved from root)
├── tmux/              # tmux terminal multiplexer configuration
├── vim/               # Vim editor configuration
└── zsh/               # Zsh shell configuration
```

## Usage

These configuration files are typically stored in your `$XDG_CONFIG_HOME` directory (usually `~/.config/`).

Use the setup script in the root directory to manage and deploy these configurations.
